# 영끌런

계약금을 모으며 지방 → 경기도 → 서울 → 강남까지 달리는 횡스크롤 점프 웹게임입니다.

- 월드 4개. 월드마다 맵 전체 계약금의 60% 이상을 모아야 끝의 "이사 심사" 대문이 열립니다.
- 세금 고지서·전세 사기꾼은 밟아서 처리, 금리 구름은 피하기. 가시 함정과 낭떠러지 주의.
- 건강 3칸, 중간 저장(중개사무소), 월드별 최고 기록 저장.
- 휴대폰은 화면 아래 ◀ ▶ 점프 버튼, 컴퓨터는 방향키와 스페이스.

등장하는 캐릭터와 사건은 모두 가상입니다. 빌드 없이 `index.html`을 열면 실행됩니다.
